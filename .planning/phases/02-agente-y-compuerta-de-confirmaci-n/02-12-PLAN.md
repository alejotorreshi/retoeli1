<objective>
Close code review WR-03, in scope by user decision. Today a session lock is released only in the generator's finally. A consumer that stops pulling without calling return() leaves the session locked for good: it never expires, never leaves the LRU count, and every later turn gets SESION_OCUPADA. Phase 3's SSE layer is exactly this kind of consumer.

The lock becomes a lease tied to the turn deadline. It also gets a fencing token, so taking over a stale lease can never let the old holder release or overwrite the new holder's session.

Purpose: re-close AGT-04 (the session survives errors and interruptions, CA5) for the abandoned-consumer path before Phase 3 builds on it, and pin it in DEMO-03 tests.
Output: the leased and fenced AlmacenSesiones port, its in-memory implementation, the turn using it, and unit and loop tests.
</objective>
