<objective>
Close verification gap 3 (code review CR-03). A step cut by finish_reason=length must never leave invalid JSON tool-call arguments in the session history. Today they are replayed in every later request, and a backend that validates `function.arguments` answers 400 (PETICION_INVALIDA, which is neither retried nor sent to the fallback), so the session becomes unusable. That breaks CA5.

Output: ARGUMENTOS_VACIOS, the pasoTruncado fix, the wire-mapper guard, a mirror unit test for the mapper, and the rewritten resilience tests.
</objective>
