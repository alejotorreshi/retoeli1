  <behavior>
    - abrir(null) creates a session through create(newId()) and returns nueva true, expirada false.
    - abrir(id) for a live id returns the same session object with nueva false, expirada false, and refreshes its last activity.
    - abrir with an unknown id, an id failing PATRON_SESION, or an id idle longer than ttlMs returns a NEW session with a different id, nueva true and expirada true, and the expired entry is gone.
    - guardar(sesion) stores and touches it. When size exceeds maxSessions, the least recently used unlocked session is evicted and a locked one never is.
    - ocupar(id) returns true once, then false until liberar(id). ocupar on an unknown id returns false.
    - Expired entries are swept on abrir and guardar, so memory stays bounded without timers.
  </behavior>
