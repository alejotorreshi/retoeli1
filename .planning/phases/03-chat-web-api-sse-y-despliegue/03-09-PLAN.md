<objective>
Give the analyst the generated files of each case: a panel lists what exists on disk, "Descargar" delivers the real file (the challenge's deliverable, D-64), and "Ver" previews it without ever showing a full value: the form and the portal values come from the masked mapeo.json (D-65, D-74), and the package texts are plain text, with the borrador's signer shown in full by the user's decision (D-74). When Render's ephemeral disk loses files, the panel says so honestly and offers to reprocess (D-67).

Purpose: API-05 and UI-06, behind the access code, with a strict whitelist and path containment.
Output: the LectorArtefactos port, its infra adapter, the artifact routes, the file list, the preview dialog and the ephemeral-disk notice, with tests for the whitelist, traversal, byte-exact downloads and PII in previews.
</objective>
