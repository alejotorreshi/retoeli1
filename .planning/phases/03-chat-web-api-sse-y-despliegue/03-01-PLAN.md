<objective>
Open the supply-chain gate for the phase's new dependencies, then build the phase tracer: a chat message travels from an HTTP client through a new Hono layer into the existing agent loop (Phase 2) and comes back as live SSE events, with a JSON fallback of the PRD 6.4 shape and a health endpoint. Phase 2 left the loop as an `AsyncGenerator<EventoAgente>`; this plan translates it to the wire without touching the loop.

Purpose: SSE over Bun is the riskiest architectural piece of the phase (Bun's 10 s idle timeout aborts silent streams and, through `cerrarTurno`, clears pending confirmations; `streamSSE` overwrites Cache-Control and leaks raw error text through its onError). Proving it end-to-end first, with a real `Bun.serve` test, catches a dead end after one commit instead of after the UI is built on top.
Output: approved and installed pins, the guarded `src/http` layer and `src/server.ts`, `POST /api/chat` (SSE plus JSON fallback), `GET /api/health`, and tests that prove ordering, headers, idle timeout, heartbeat, abort, encoding and error containment.
</objective>
