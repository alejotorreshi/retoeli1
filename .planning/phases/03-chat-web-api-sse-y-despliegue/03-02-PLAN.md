<objective>
Put the chat in the browser. `bun run dev` starts the API and Vite together; the analyst types a message and watches the agent answer live, with the thinking indicator and clear errors. The API server also serves the built SPA, which is what Render will run. A guardian for `web/` lands before the components so all UI code is born under the project rules (no comments, strings in one file, no HTML injection, no browser storage of secrets).

Purpose: the browser half of the tracer. After this plan a real user can converse with the agent in a web page (UI-01, UI-04) with one command (DEP-01).
Output: the Vite + React 19 app under web/, the SSE client and the pure reducer, the UI-SPEC base components and tokens, static serving from Hono, the web guardian and its docs.
</objective>
