<objective>
Build the chat tracer on top of the running skeleton of plan 03-01: a chat message travels from an HTTP client through the Hono layer into the existing agent loop (Phase 2) and comes back as live SSE events, with a JSON fallback of the PRD 6.4 shape. Phase 2 left the loop as an `AsyncGenerator<EventoAgente>`; this plan translates it to the wire without touching the loop.

Purpose: SSE over Bun is the riskiest architectural piece of the phase (Bun's 10 s idle timeout aborts silent streams and, through `cerrarTurno`, clears pending confirmations; `streamSSE` overwrites Cache-Control and leaks raw error text through its error callback). Proving it end-to-end, with a real `Bun.serve` test, catches a dead end before the UI is built on top.
Output: `POST /api/chat` (SSE plus JSON fallback), app-level not-found and error handlers, the shared test helper, and tests that prove ordering, headers, idle timeout, heartbeat, abort, encoding and error containment.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → /api/chat | Untrusted body and connection lifetime enter the server |
| agent loop → SSE frames | Loop events may carry secrets or internal error text toward the client |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Information disclosure | chat.route.ts stream errors | high | mitigate | Own try/catch inside the streamSSE callback writes only MENSAJE_HTTP.errorInterno; streamSSE never receives an error callback (it would write the raw message); the app-level error handler in server.wiring.ts returns { mensaje } and logs through pino with redaction; tested in stream.test.ts |
| T-03-02 | Denial of service | Bun idle timeout on SSE/JSON | high | mitigate | c.env.timeout(c.req.raw, 0) on both paths plus an 8 s heartbeat; a real Bun.serve test with idleTimeout 1 s proves the turn survives, so pending confirmations are not wiped by a spurious abort |
| T-03-03 | Information disclosure | SSE frames | high | mitigate | toSseFrame passes every event through redactar(evento, secrets) with secretosDelAgente; salud.test.ts and chat.test.ts assert CLAVE_PRUEBA never appears |
| T-03-04 | Denial of service | abandoned streams | medium | mitigate | stream.onAbort aborts the turn's AbortController, so a closed tab stops the provider call; tested with a hung provider request |
| T-03-SC | Tampering | npm installs | high | mitigate | No new package in this plan; the pins approved in 03-01 Task 1 stay exact with bun.lock and bun audit in bun run check |
</threat_model>
