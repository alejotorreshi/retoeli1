<objective>
Close the public link behind a shared access code, following D-72: the analyst types the code once, the server answers with an HttpOnly signed cookie that lasts 12 hours, and every protected endpoint checks it (curl can use Bearer). Then harden the API edge required by API-04 and D-73 items 2 and 4: a brute-force limit on failed codes keyed by the real client IP, JSON-only POSTs, a body limit before parsing, the message limit, and security headers with a strict CSP. The header now shows the effective execution date (UI-09).

Purpose: this must exist before the first public deploy (plan 03-04), because an open /api/chat on a public link would let anyone spend the prepaid LLM balance.
Output: access route, middleware, token service, config endpoint, limiter and client-IP services, edge middlewares, the access screen, the date in the header, and tests that prove each layer cuts.
</objective>
