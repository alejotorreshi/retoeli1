<objective>
Make the agent's work visible: every tool call is a card with its case and result, a thinking indicator names the tool in flight, a per-case result card shows counters, signature readiness, blockers and the output path, and a side panel shows each case's progress through six stages. Quick-action chips start the PRD §11 demo, the four cases, or the case listing, which works with the existing five tools.

Purpose: UI-01, UI-02, UI-05, UI-07 and the progress half of UI-08, with the structured data built on the server from tool results only (CONTEXT discretion, UI-SPEC data contract items 1 and 2) so the UI never parses model text.
Output: `caso` and `resultado` in tool events, the result projection service, the knowledge tweak for listing cases, and the tool, result, progress, panel and chip components with their pure state.
</objective>
