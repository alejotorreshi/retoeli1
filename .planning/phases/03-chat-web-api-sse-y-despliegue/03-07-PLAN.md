<objective>
Turn the server's confirmation gate into per-case cards with Confirmar and Cancelar buttons. The buttons send a visible message plus a structured accion that the server honors only for a pending case (D-68), and Cancelar removes only that case (D-69), fixing the Phase 2 limitation where the structured rejection cancelled every pending case (WR-17). The cards never decide anything locally: they open, stay, close or get replaced only from the next turn's events.

Purpose: UI-03 and CA3 (the front highlights the confirmation), with the server remaining the only gate.
Output: TIPO_ACCION, the CANCELA_CASO decision, accion through the API and the loop, readable blockers in confirmation_required, the card component and its pure state machine, and the updated gate tests.
</objective>
