Las dos brechas nuevas tienen una sola causa: el limitador de `/api/acceso` (D-77 / D-73.2).

1. **CR-01 (regresión introducida por 03-41).** El cupo de desalojos, agregado como desvío Rule 2 para acotar la rotación en ronda, hace que el limitador falle cerrado sin ninguna clave bloqueada.
