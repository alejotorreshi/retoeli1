## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Repository → public GitHub/Render build | Files in the repo become build inputs and possibly public |
| Render edge (Cloudflare) → container | Proxy may buffer streams and rewrites forwarding headers |
| Container runtime → host | Process privileges inside the image |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-16 | Information disclosure | LLM key, access code and HMAC secret in bundle, responses or stream | high | mitigate | tests/seguridad/clave.test.ts sentinel scan over a fresh Vite build, every API response, SSE frames and a 402 path, including three concurrent turns; no VITE_ names |
| T-03-17 | Information disclosure | Secrets committed in render.yaml or .env.example | high | mitigate | sync: false for LLM_API_KEY and ACCESS_CODE, generateValue for ACCESS_TOKEN_SECRET, .env.example values empty; contract test enforces it |
| T-03-18 | Elevation of privilege | Container running as root | medium | mitigate | USER bun in the runtime stage, out/ chowned to bun; contract test checks USER bun |
| T-03-19 | Denial of service | SSE buffering at Render's edge | medium | mitigate | Cache-Control no-cache, no-transform and X-Accel-Buffering no from 03-02; live timing probe in Task 3; buffering triggers a user decision (JSON fallback or plan B host) |
| T-03-SC | Tampering | npm installs in the image | high | mitigate | bun install --frozen-lockfile in both stages with the committed bun.lock; production stage installs only dependencies |
</threat_model>
