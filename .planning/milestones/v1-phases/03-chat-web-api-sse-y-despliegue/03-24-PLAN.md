<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL path params (caso, nombre) → file system | Client-controlled names reach disk lookups |
| Generated files → browser | Real values exist in the files; previews must not show them |
| Downloaded content → browser handling | Files could be sniffed or rendered inline |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-30 | Information disclosure | Path traversal or whitelist bypass on downloads | high | mitigate | caso checked by PATRON_CASO and listCases, exact match against the computed whitelist (no concatenation of input), realpath containment via safe-paths, symlink escape test, 404 for mapeo.json and log.jsonl |
| T-03-31 | Information disclosure | PII in previews | high | mitigate | Form and portal previews only from the masked mapeo.json; PII scan over every preview of the four cases with the single D-74 borrador allowance |
| T-03-32 | Tampering | Content sniffing or inline rendering of downloads | medium | mitigate | Content-Disposition attachment, explicit content types, nosniff from secureHeaders; previews are JSON rendered as React text |
| T-03-SC | Tampering | npm installs | high | mitigate | No new package in this plan; exact pins, bun.lock and bun audit in bun run check |
</threat_model>
