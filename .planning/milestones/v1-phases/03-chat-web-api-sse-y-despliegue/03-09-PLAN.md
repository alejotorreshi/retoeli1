<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP path → static file system | Request paths map to files under web/dist |
| Request body → JSON parser | Untrusted size and content type |
| Cross-site pages → POST /api/chat | A browser holding the cookie could be driven by another origin |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-08 | Information disclosure | Static file traversal | medium | mitigate | serveStatic rooted at web/dist with SPA fallback; tests/http/estatico.test.ts proves an encoded ../ path returns index.html, not package.json |
| T-03-11 | Tampering | CSRF on POST /api/chat | medium | mitigate | SameSite=Strict cookie (03-04) plus JSON-only middleware (415) that forces a preflight cross-origin |
| T-03-13 | Denial of service | Oversize bodies and long messages | medium | mitigate | bodyLimit 16 KB before parsing, 2000-character message limit, both configurable and tested at the boundary |
| T-03-15 | Tampering | Script injection via the SPA | medium | mitigate | secureHeaders with CSP script-src 'self', frame-ancestors 'none', nosniff |
| T-03-SC | Tampering | npm installs | high | mitigate | No new package in this plan; existing exact pins, bun.lock and bun audit in bun run check |
</threat_model>
